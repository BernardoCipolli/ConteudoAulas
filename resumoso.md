# 🖥️ História dos Sistemas Operacionais (SO)

> 📚 Uma visão geral da evolução dos Sistemas Operacionais, desde os primeiros computadores até os dispositivos modernos.

---

## 🧠 O que é um Sistema Operacional?

O **Sistema Operacional (SO)** é o software que faz a comunicação entre o **usuário 👤**, os **programas 📱** e o **hardware 💻**.

```text
        👤 USUÁRIO
             │
             ▼
      🖥️ SISTEMA OPERACIONAL
       ┌─────┼─────┐
       ▼     ▼     ▼
     🧠 CPU  💾 RAM  📁 DISCO
             │
             ▼
        🔌 HARDWARE
```

### 🎯 Principais funções

* 🧠 Gerenciar o processador (CPU)
* 💾 Gerenciar a memória
* 📁 Organizar arquivos e armazenamento
* 🔌 Controlar dispositivos
* 🔐 Gerenciar segurança e usuários
* 🌐 Gerenciar redes
* 🖱️ Fornecer uma interface para o usuário
* ⚙️ Permitir a execução de programas

# 🕰️ 1. Primeira geração — anos 1940

### ❌ Ainda não existiam Sistemas Operacionais

Os primeiros computadores eletrônicos eram enormes e extremamente limitados.

Os programas eram inseridos diretamente na máquina utilizando:

* 🃏 Cartões perfurados
* 🎞️ Fitas
* 🔘 Chaves e painéis

Cada computador executava basicamente **uma tarefa por vez**.

```text
👨‍💻 Programador
      │
      ▼
🃏 Cartões perfurados
      │
      ▼
🖥️ Computador
      │
      ▼
📊 Resultado
```

---

# 📦 2. Segunda geração — anos 1950

Com a utilização dos **transistores 🔬**, os computadores ficaram menores, mais rápidos e mais confiáveis.

Foi nesse período que surgiu o conceito de **processamento em lote (Batch Processing)**.

### 📦 Como funcionava?

Vários programas eram agrupados:

```text
📄 Programa A
📄 Programa B
📄 Programa C
📄 Programa D
       │
       ▼
   📦 LOTE
       │
       ▼
🖥️ COMPUTADOR
       │
       ▼
📊 Resultados
```

Isso permitiu aproveitar melhor o tempo de processamento.

---

# 🔄 3. Terceira geração — anos 1960

Os **circuitos integrados 🔬** trouxeram computadores mais poderosos.

Os sistemas operacionais começaram a ficar muito mais sofisticados.

### 🚀 Principais avanços

| Tecnologia                  | Função                                      |
| --------------------------- | ------------------------------------------- |
| 🔄 Multiprogramação         | Vários programas na memória                 |
| ⏱️ Time-sharing             | Vários usuários compartilhando o computador |
| 📦 Batch                    | Execução automática de lotes                |
| 💾 Gerenciamento de memória | Controle da memória disponível              |
| 📁 Sistemas de arquivos     | Organização dos dados                       |

## 🐚 UNIX

No final dos anos 1960 surgiu o **UNIX**, que se tornou extremamente importante para a história dos sistemas operacionais.

Sua influência pode ser representada assim:

```text
                 🐚 UNIX
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
      🐧 Linux     🍎 macOS    🖥️ BSD
        │
        ▼
   ☁️ Servidores
   📱 Android
   🌐 Internet
```

# 💻 4. Quarta geração — anos 1970 e 1980

A invenção dos **microprocessadores ⚡** ajudou a popularizar os computadores pessoais.

Agora, o computador começou a sair dos grandes centros de pesquisa e chegar às casas e empresas.

### 🖥️ Sistemas importantes

* 📟 CP/M
* 💾 MS-DOS
* 🍎 Apple DOS
* 🪟 Windows
* 🍎 Mac OS

### 🎨 Surgimento das interfaces gráficas

Antes:

```text
C:\> DIR
C:\> COPY ARQUIVO.TXT
C:\> DEL ARQUIVO.TXT
```

Depois:

```text
       🖥️
   ┌───────────┐
   │ 📁 📄 🗑️  │
   │           │
   │ 🖱️        │
   └───────────┘
```

A interface gráfica tornou os computadores muito mais acessíveis.

---

# 🌐 5. Anos 1990

A década de 1990 foi marcada pela popularização dos computadores pessoais e da Internet 🌐.

### ⭐ Destaques

🪟 **Windows** → grande expansão nos computadores pessoais

🐧 **Linux** → crescimento do software livre e dos servidores

🍎 **macOS** → evolução dos computadores Macintosh

🌐 **Internet** → aumento da importância das redes

### 🐧 Linux

Em **1991**, Linus Torvalds iniciou o desenvolvimento do Linux.

O projeto ganhou grande importância por utilizar uma filosofia de **código aberto 🔓**.

---

# 📱 6. Anos 2000

Os Sistemas Operacionais começaram a se tornar cada vez mais presentes em dispositivos além do computador tradicional.

```text
              🖥️ COMPUTADOR

       ┌────────────┼────────────┐
       ▼            ▼            ▼
     📱 CELULAR    🎮 CONSOLE   📺 TV
       │
       ▼
     🤖 Android
     🍎 iOS
```

Também houve avanços importantes em:

* 🌐 Internet
* 🔐 Segurança
* ☁️ Computação em nuvem
* 📱 Mobilidade
* 🎮 Jogos
* 🔄 Atualizações automáticas
