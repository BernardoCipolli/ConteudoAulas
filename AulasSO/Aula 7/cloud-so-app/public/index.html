IMPORTANTE

Servidor x seu computador

Quando o projeto roda localmente, as métricas do backend representam seu computador. Quando ele está hospedado no Render, CPU, RAM, discos, processos e GPU do backend pertencem ao servidor/container do Render. A área “Seu dispositivo” é coletada pelo navegador e continua mostrando informações disponíveis do computador que está acessando o site.
