
# 💻 Como Formatar um Computador

## 📚 Sobre

Este documento apresenta um guia básico e informativo sobre como formatar um computador, explicando as etapas necessárias para realizar a instalação de um sistema operacional do zero.

A formatação é um processo utilizado para apagar os dados de uma unidade de armazenamento e preparar o computador para receber um novo sistema operacional.

## 🎯 Objetivos

- Entender o que é formatação.
- Conhecer os materiais necessários.
- Aprender as etapas básicas do processo.
- Entender como instalar um sistema operacional.
- Conhecer os cuidados necessários antes da formatação.

## 🛠️ Materiais necessários

- Computador ou notebook.
- Pendrive de pelo menos 8 GB.
- Arquivo ISO do sistema operacional.
- Programa para criar um pendrive bootável.
- Conexão com a internet.
- Backup dos arquivos importantes.

## ⚙️ Etapas da formatação

### 1. Fazer backup dos arquivos

Antes de formatar, salve seus arquivos importantes em outro dispositivo ou serviço de armazenamento.

Exemplos:
- Fotos e vídeos.
- Documentos.
- Trabalhos acadêmicos.
- Arquivos pessoais.
- Senhas e informações importantes.

**Atenção:** a formatação pode apagar permanentemente os arquivos armazenados na unidade selecionada.

### 2. Baixar o sistema operacional

Escolha o sistema operacional que deseja instalar.

Exemplos:

- [Windows 11](https://www.microsoft.com/software-download/windows11)
- [Ubuntu Linux](https://ubuntu.com/download/desktop)

Sempre utilize fontes oficiais para baixar o sistema.

### 3. Criar um pendrive bootável

Utilize um programa como o Rufus para preparar o pendrive com o sistema operacional.

Site oficial:

https://rufus.ie/

O processo consiste em selecionar:
- O pendrive.
- A imagem ISO do sistema.
- As configurações de inicialização.

### 4. Iniciar o computador pelo pendrive

Com o pendrive conectado, reinicie o computador e acesse o menu de inicialização (Boot Menu).

A tecla utilizada depende do fabricante e modelo do computador.

Exemplos comuns:
- F12
- F11
- F9
- ESC

Selecione o pendrive para iniciar o instalador.

### 5. Instalar o sistema operacional

Depois de iniciar pelo pendrive:

1. Selecione o idioma.
2. Configure as opções regionais.
3. Inicie a instalação.
4. Escolha o tipo de instalação.
5. Selecione cuidadosamente a unidade ou partição de destino.
6. Prossiga com a instalação.

**Atenção:** confira duas vezes a unidade selecionada antes de excluir ou formatar partições.

### 6. Configurar o computador

Após a instalação:

- Configure o usuário.
- Ajuste data e horário.
- Conecte à internet.
- Instale as atualizações.
- Configure as preferências do sistema.

### 7. Instalar drivers e programas

Instale os drivers necessários para o funcionamento correto do computador.

Exemplos:
- Driver de vídeo.
- Driver de áudio.
- Driver de rede.
- Driver de chipset.

Baixe os drivers preferencialmente nos sites oficiais dos fabricantes.

## ⚠️ Cuidados importantes

- Faça backup antes de iniciar.
- Mantenha o computador conectado à energia.
- Utilize imagens oficiais do sistema operacional.
- Não interrompa a instalação.
- Verifique a compatibilidade do computador.
- Tenha em mãos as licenças necessárias.
- Confira se possui as chaves de recuperação do BitLocker ou de outras criptografias, quando aplicável.

## 📌 Conclusão

A formatação de um computador é um procedimento importante para reinstalar ou substituir um sistema operacional.

Seguindo as etapas corretamente e tomando os cuidados necessários, é possível realizar uma instalação limpa e preparar o computador para utilização novamente.
