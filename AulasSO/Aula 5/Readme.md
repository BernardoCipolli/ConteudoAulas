
# 🖥️ Manual Informativo - VirtualBox

## 📚 Sobre

Este documento apresenta informações sobre o VirtualBox, um software de virtualização que permite criar e executar máquinas virtuais em um computador físico.

Com ele, é possível instalar e utilizar diferentes sistemas operacionais sem precisar alterar o sistema principal do computador.

O VirtualBox é bastante utilizado para estudos, testes, desenvolvimento de software e aprendizado sobre sistemas operacionais.

## 🎯 Objetivos

- Entender o que é virtualização.
- Conhecer a finalidade do VirtualBox.
- Aprender os principais conceitos de máquinas virtuais.
- Conhecer os recursos disponíveis no programa.
- Entender como funciona a instalação de sistemas operacionais virtuais.

## 💻 O que é VirtualBox?

O VirtualBox é um software de virtualização desenvolvido pela Oracle.

Ele permite executar um sistema operacional dentro de outro, utilizando recursos de hardware do computador físico.

Por exemplo:

- Computador principal com Windows.
- Máquina virtual com Linux.
- Outra máquina virtual com Windows.

Tudo isso pode funcionar no mesmo computador, respeitando os recursos disponíveis.

## 🛠️ Requisitos básicos

Para utilizar o VirtualBox, é recomendado possuir:

- Computador ou notebook compatível.
- Processador com suporte à virtualização.
- Memória RAM suficiente.
- Espaço disponível no armazenamento.
- Imagem ISO do sistema operacional desejado.

Os requisitos variam conforme o sistema operacional que será instalado na máquina virtual.

## ⚙️ O que é uma máquina virtual?

Uma máquina virtual é um computador criado por software.

Ela possui recursos virtuais que simulam os componentes de um computador físico.

Entre eles:

- Processador virtual.
- Memória RAM virtual.
- Disco rígido virtual.
- Placa de rede virtual.
- Adaptador gráfico virtual.

Esses recursos são utilizados para executar um sistema operacional independente dentro do computador principal.

## 🖥️ Como criar uma máquina virtual?

O processo de criação de uma máquina virtual envolve algumas etapas:

1. Abrir o VirtualBox.
2. Selecionar a opção de criar uma nova máquina virtual.
3. Definir o nome da máquina.
4. Escolher o sistema operacional.
5. Configurar a quantidade de memória RAM.
6. Definir a quantidade de processadores virtuais.
7. Criar um disco rígido virtual.
8. Selecionar a imagem ISO do sistema operacional.
9. Iniciar a máquina virtual.

## 💿 O que é uma imagem ISO?

Uma imagem ISO é um arquivo que contém uma cópia dos dados de um disco de instalação.

Ela é utilizada para instalar sistemas operacionais em máquinas físicas ou virtuais.

Exemplos:

- Windows 11.
- Ubuntu.
- Debian.
- Linux Mint.

## 🔧 Principais funcionalidades

### 1. Snapshots

Permitem salvar o estado de uma máquina virtual em determinado momento.

São úteis para recuperar um estado anterior após testes ou alterações.

### 2. Clonagem

Permite criar uma cópia de uma máquina virtual existente.

### 3. Pastas compartilhadas

Permitem compartilhar arquivos entre o sistema principal e a máquina virtual.

### 4. Rede virtual

Permite configurar diferentes formas de conexão de rede para a máquina virtual.

### 5. Discos virtuais

Permitem armazenar os arquivos e dados do sistema operacional instalado na máquina virtual.

### 6. Modo de tela cheia

Permite visualizar a máquina virtual ocupando toda a tela do computador.

## 🌐 Tipos de rede no VirtualBox

O VirtualBox oferece diferentes modos de conexão de rede.

| Modo | Descrição |
|---|---|
| NAT | Permite que a máquina virtual acesse a internet usando a conexão do computador principal. |
| Bridge | Conecta a máquina virtual à rede física como se fosse outro dispositivo. |
| Rede Interna | Permite comunicação entre máquinas virtuais na mesma rede interna. |
| Host-only | Permite comunicação entre o computador principal e as máquinas virtuais. |

## 📌 Vantagens do VirtualBox

- Permite testar diferentes sistemas operacionais.
- Não exige outro computador físico.
- Facilita estudos sobre sistemas operacionais.
- Permite criar ambientes de testes.
- Possibilita utilizar snapshots.
- Ajuda no aprendizado de redes e infraestrutura.

## ⚠️ Cuidados importantes

- Verifique a quantidade de memória RAM disponível.
- Não configure mais recursos virtuais do que o computador suporta.
- Faça cópias de segurança das máquinas virtuais importantes.
- Utilize imagens ISO de fontes confiáveis.
- Mantenha o VirtualBox atualizado.
- Tenha cuidado ao configurar redes e pastas compartilhadas.

## 📖 Exemplos de utilização

O VirtualBox pode ser utilizado em diversas atividades:

- Estudar Linux sem remover o Windows.
- Aprender a instalar sistemas operacionais.
- Testar programas em ambientes separados.
- Estudar redes de computadores.
- Simular ambientes de servidores.
- Aprender conceitos de infraestrutura e virtualização.
