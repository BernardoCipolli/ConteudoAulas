
# 💻 História dos Sistemas Operacionais (SO)

## 📚 Sobre o projeto

Este repositório tem como objetivo estudar e documentar a evolução histórica dos **Sistemas Operacionais (SO)**, desde os primeiros computadores até os sistemas modernos utilizados atualmente.

Aqui serão apresentados os principais acontecimentos, tecnologias, conceitos e sistemas que marcaram a evolução da computação.

## 🎯 Objetivos

- Compreender o surgimento dos sistemas operacionais.
- Conhecer a evolução dos sistemas ao longo das décadas.
- Identificar os principais sistemas operacionais da história.
- Entender como os sistemas operacionais influenciaram a tecnologia atual.
- Registrar conhecimentos adquiridos durante os estudos.

## 🕒 Linha do tempo dos Sistemas Operacionais

| Período | Acontecimento |
|---|---|
| Década de 1940 | Computadores sem sistemas operacionais modernos. |
| Década de 1950 | Surgimento dos primeiros sistemas de processamento em lote (Batch). |
| Década de 1960 | Desenvolvimento de multiprogramação e compartilhamento de tempo. |
| Década de 1970 | Expansão do UNIX. |
| Década de 1980 | Popularização dos computadores pessoais e do MS-DOS. |
| Década de 1990 | Expansão do Windows e do Linux. |
| Década de 2000 | Crescimento dos sistemas móveis e da computação em nuvem. |
| Década de 2010 | Evolução dos sistemas móveis, virtualização e segurança. |
| Década de 2020 | Avanços em inteligência artificial, nuvem e sistemas distribuídos. |

## 🖥️ Principais Sistemas Operacionais

### UNIX
Um dos sistemas mais importantes da história, influenciando diversos sistemas modernos.

### MS-DOS
Sistema operacional desenvolvido para computadores pessoais, muito utilizado na década de 1980.

### Windows
Sistema operacional da Microsoft que popularizou interfaces gráficas nos computadores pessoais.

### Linux
Sistema operacional de código aberto, amplamente utilizado em servidores, computadores e dispositivos embarcados.

### macOS
Sistema operacional da Apple, conhecido por sua interface gráfica e integração com o hardware da empresa.

### Android
Sistema operacional baseado no kernel Linux, desenvolvido principalmente para dispositivos móveis.

### iOS
Sistema operacional móvel desenvolvido pela Apple para seus dispositivos.

## 📖 Conceitos importantes

- **Kernel:** núcleo responsável pelo gerenciamento dos recursos do sistema.
- **Processos:** programas em execução.
- **Memória:** gerenciamento e distribuição da memória do computador.
- **Sistema de arquivos:** organização e armazenamento de dados.
- **Multitarefa:** capacidade de executar múltiplos processos.
- **Interface gráfica:** interação do usuário com o sistema por elementos visuais.
