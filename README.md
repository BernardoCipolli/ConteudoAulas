## 📖 Sobre

Esta pasta faz parte do repositório **ConteudoAulas** e é dedicada à organização dos materiais da disciplina de **Sistemas Operacionais (SO)**.

O objetivo é centralizar os conteúdos utilizados durante os estudos, facilitando o acesso às aulas, a revisão dos conceitos e a consulta às atividades práticas.

## 🎯 Objetivos de aprendizagem

- Compreender a função de um sistema operacional e sua relação com o hardware e os aplicativos.
- Estudar como recursos computacionais são administrados.
- Conhecer conceitos de processos, threads, escalonamento e gerenciamento de memória.
- Entender sistemas de arquivos, permissões e organização de dados.
- Explorar ambientes e ferramentas usados em atividades práticas de Sistemas Operacionais.

## 🧠 Principais temas da disciplina

> Os itens abaixo apresentam **temas gerais de Sistemas Operacionais** e não representam necessariamente o índice dos arquivos já presentes nesta pasta.

| Tema | Descrição |
| --- | --- |
| Introdução aos SO | Conceitos, funções, tipos e evolução dos sistemas operacionais. |
| Processos e threads | Execução concorrente e gerenciamento de tarefas. |
| Escalonamento | Critérios e algoritmos de distribuição do tempo de CPU. |
| Gerenciamento de memória | Alocação, memória virtual e paginação. |
| Sistemas de arquivos | Estrutura de diretórios, armazenamento e permissões. |
| Entrada e saída | Comunicação com periféricos e dispositivos. |
| Virtualização | Criação e utilização de máquinas virtuais. |
| Linux e comandos | Navegação, operações básicas e administração pelo terminal. |

## 📁 Como explorar os arquivos

1. Acesse a [pasta **AulasSO**](https://github.com/BernardoCipolli/ConteudoAulas/tree/main/AulasSO).
2. Abra o material da aula ou atividade que deseja consultar.
3. Para arquivos de texto ou código, utilize a visualização do próprio GitHub.
4. Para atividades práticas, siga as orientações incluídas no respectivo material.

### Clonar o repositório

Se quiser acessar os materiais localmente, execute:

```bash
git clone https://github.com/BernardoCipolli/ConteudoAulas.git
cd ConteudoAulas/AulasSO
```

> **Pré-requisito:** ter o Git instalado. Eventuais softwares adicionais dependem de cada atividade.
